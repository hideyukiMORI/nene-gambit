# 要件と施主の決定 — NeNe Gambit

> Status: normative（規範）/ 2026-10-25 初版
> 施主（hide）が言ったことだけを書く。**施主が言っていない機能を要件に書かない・実装しない。** 未決は答えが出てから要件に上げる。

## 1. 要件（FR）

| ID | 要件 |
| --- | --- |
| FR-01 | 端末に盤面を描き、白と黒の AI が 1 手ずつ交互に指す様子を見せる |
| FR-02 | 指し手生成は合法手を完全に扱う（キャスリング・アンパッサン・昇格 4 種・ピン・チェック回避）。perft で深さ 5 まで公表値と一致することをゲートで確かめる |
| FR-03 | AI は評価関数（駒の価値＋駒ごとの位置の表）＋アルファベータ探索で手を選ぶ |
| FR-04 | 終局判定: チェックメイト・ステイルメイト・同一局面 3 回・50 手ルール・駒不足。どれかで終局したら結果を見せ、次の局を自動で始める |
| FR-05 | 毎回違う対局になる（序盤の数手をランダムにする・評価が同点の手から乱数で選ぶ） |
| FR-06 | 白と黒で強さや性格を変えられる（探索の深さ・評価の重み）。勝ち負けにばらつきを出す |
| FR-07 | 駒の表示は既定が英字（`K Q R B N P`・白と黒は色で分ける）。Unicode の駒記号はオプション。切り替えは起動オプションと実行中のキーの両方 |
| FR-08 | `q` で終了する。どんな終わり方でも端末を元に戻す |
| FR-09 | 動作環境: WSL2 の Ubuntu＋Windows Terminal |
| FR-10 | 盤の横（HUD）に、直近の棋譜数手・通算の勝敗（白勝ち / 黒勝ち / 引き分け）と局数・手番と手数・白黒の性格名を出す |
| FR-11 | 1 手を指す間隔の初期値は 0.7 秒、終局後に結果を見せる時間の初期値は 3 秒。起動オプションで変えられる |
| FR-12 | 盤の配色は 1 テーマから始める（テーマの切り替えは作らない） |
